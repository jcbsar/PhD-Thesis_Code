# 04 - Multivariate Genome-Wide Association Studies

## Purpose

This directory documents the multivariate genome-wide association studies (GWAS) conducted using Genomic Structural Equation Modelling (Genomic SEM) in Chapter 3 of the thesis.

The analyses investigated SNP associations with latent genetic factors representing generalised genetic epilepsy (GGE), focal epilepsy (FE) and subcortical brain volumes. Multivariate GWAS were conducted using `GenomicSEM::userGWAS()` with chromosome-partitioned, harmonised GWAS summary statistics on the University of Cape Town high-performance computing (HPC) cluster.

Three analyses are documented:

1. The primary GGE–brain multivariate GWAS using the corrected GGE LDSC covariance object.
2. The FE–brain multivariate GWAS.
3. A GGE sensitivity analysis excluding childhood absence epilepsy (CAE).

The repository provides a consolidated workflow for input preparation, chromosome-level model execution, result combination and independent output validation. The original genome-wide results are retained in research archives, while the scripts provided here represent the consolidated implementation of the documented analyses.

## Analysis specifications

### Primary GGE–brain model

The GGE model comprised four epilepsy indicators (CAE, GTCS, JAE and JME) and six subcortical brain-volume indicators (accumbens, amygdala, caudate, pallidum, putamen and thalamus).

The model specified correlated GGE and brain-volume latent factors, with the residual variance of CAE constrained to zero.

```r
GGE =~ CAE + GTCS + JAE + JME
Brain =~ accumbens + amygdala + caudate +
         pallidum + putamen + thalamus

CAE ~~ 0*CAE

GGE ~~ Brain

GGE ~ SNP
Brain ~ SNP
```

The definitive primary multivariate GWAS used the corrected ten-phenotype LDSC covariance object:

`ldsc_GGE_brain_6region_corrected.rds`

This object is distinct from the July-derived GGE covariance input used to reproduce the retained CFA results. The corresponding LDSC specifications and analytical provenance are documented in `02_GenomicSEM_LDSC`.

### FE–brain model

The FE model comprised three focal epilepsy indicators (F_HS, F_Neg and F_Oth) and the same six subcortical brain-volume indicators.

```r
FE =~ F_HS + F_Neg + F_Oth
Brain =~ accumbens + amygdala + caudate +
         pallidum + putamen + thalamus

FE ~~ Brain

FE ~ SNP
Brain ~ SNP
```

The FE multivariate GWAS used:

`ldsc_FE_brain_6region.rds`

Both the FE and brain-volume factor associations were estimated simultaneously within this model.

### GGE sensitivity analysis excluding CAE

To assess the influence of CAE on the multivariate GGE findings, an additional analysis excluded CAE from the epilepsy factor.

The sensitivity model retained GTCS, JAE and JME as GGE indicators alongside the six subcortical brain-volume indicators.

```r
GGE =~ GTCS + JAE + JME
Brain =~ accumbens + amygdala + caudate +
         pallidum + putamen + thalamus

GGE ~~ Brain

GGE ~ SNP
Brain ~ SNP
```

The sensitivity analysis used an independently estimated nine-phenotype LDSC covariance object:

`ldsc_GGE_no_CAE_brain_6region.rds`

The object was generated by re-estimating LDSC without CAE, rather than extracting a reduced covariance matrix from the primary GGE object.

At the SNP level, the harmonised primary GGE input was retained, with `beta.CAE` and `se.CAE` excluded before model estimation. This approach preserved the remaining SNP identities and harmonised allele information.

The LDSC preparation procedure and prevalence assumptions are documented in `02_GenomicSEM_LDSC/scripts/02_prepare_GGE_no_CAE_LDSC.R`.

The computational label `GTCS` corresponds to GTCSA in the thesis. Similarly, `F_HS`, `F_Neg` and `F_Oth` correspond to F-HS, F-Neg and F-Oth.

## Multivariate GWAS estimation

All three analyses used `GenomicSEM::userGWAS()` with a common estimation framework.

| Parameter | Specification |
|---|---|
| Estimation | Diagonally weighted least squares (`DWLS`) |
| Measurement model | Fixed (`fix_measurement = TRUE`) |
| SNP heterogeneity testing | `Q_SNP = TRUE` |
| Genetic covariance adjustment | `GC = "standard"` |
| Smoothing diagnostics | `smooth_check = TRUE` |
| Latent variance standardisation | `std.lv = FALSE` |
| Numerical tolerance option | `toler = FALSE` |
| SNP standard errors option | `SNPSE = FALSE` |
| MPI | `FALSE` |
| Genome-wide significance | p < 5 × 10⁻⁸ |

Each model estimated the association of SNP effects with both the epilepsy and common brain-volume latent factors.

The output retained effect estimates, standard errors, association statistics, Q-SNP heterogeneity statistics, model warnings and smoothing diagnostics.

The Q-SNP statistic was used to evaluate heterogeneity in SNP effects across the indicators of a latent factor. These heterogeneity results are distinct from the primary SNP–factor association tests.

## Reproducible workflow

The workflow is organised into four sequential stages, supported by six scripts.

| Script | Function |
|---|---|
| `01_prepare_inputs.R` | Validate the harmonised GGE and FE SNP datasets and partition them into 22 autosomal chromosome files |
| `02_run_userGWAS.R` | Execute corrected GGE, FE or CAE-exclusion multivariate GWAS for a chromosome or chromosome chunk |
| `02_submit_userGWAS.sh` | Submit chromosome-level GWAS jobs through SLURM |
| `03_combine_results.R` | Validate and combine chromosome-level SNP associations for both latent factors |
| `03_submit_combine.sh` | Submit result-combination jobs through SLURM |
| `04_validate_results.R` | Independently validate combined genome-wide results and produce QC reports |

All three models are implemented in `02_run_userGWAS.R`, avoiding duplicated model-execution code. The combination and validation scripts are likewise shared across analyses.

### Stage 1: Validate and partition harmonised SNP inputs

`01_prepare_inputs.R` validates the required SNP and phenotype columns, expected SNP counts, autosomal chromosome assignments and SNP identifier uniqueness.

It then partitions the GGE and FE datasets into separate compressed RDS files for chromosomes 1–22 and records chromosome-level SNP counts.

For input validation without generating chromosome files:

```bash
Rscript 01_prepare_inputs.R \
  "/path/to/GGE_brain_sumstats.rds" \
  "/path/to/FE_brain_sumstats.rds" \
  "/path/to/output/input_by_chr" \
  --check-only
```

To generate the chromosome inputs, omit `--check-only`.

The output structure is:

```text
input_by_chr/
├── GGE_brain/
│   ├── chr01_sumstats.rds
│   ├── ...
│   ├── chr22_sumstats.rds
│   └── GGE_split_summary.csv
└── FE_brain/
    ├── chr01_sumstats.rds
    ├── ...
    ├── chr22_sumstats.rds
    └── FE_split_summary.csv
```

The script refuses to overwrite nonempty chromosome-output directories. New full executions should therefore use a clean analysis directory.

### Stage 2: Execute chromosome-level multivariate GWAS

`02_run_userGWAS.R` implements the three analysis-specific models and their corresponding LDSC covariance inputs.

The runner accepts an analysis identifier:

- `GGE`: corrected primary GGE–brain model.
- `FE`: focal epilepsy–brain model.
- `GGE_no_CAE`: sensitivity analysis excluding CAE.

Each run produces an RDS file containing both latent-factor association tables, model metadata and session information.

The SLURM launcher `02_submit_userGWAS.sh` submits chromosome-level jobs with the following configuration:

| Analysis | SLURM array | CPUs per task | Memory per task | Time limit |
|---|---|---:|---:|---|
| GGE | `1-22%4` | 4 | 48 GB | 24 hours |
| FE | `1-22%4` | 4 | 48 GB | 24 hours |
| GGE excluding CAE | `1-23%4` | 1 | 48 GB | 24 hours |

For the CAE-exclusion analysis, chromosome 2 is processed in two chunks, consistent with the computational strategy used in the original analysis.

The runner supports chromosome chunking directly, eliminating the need for separate chromosome 2 execution and CSV-repair scripts.

To preview the SLURM configuration without submitting jobs:

```bash
bash 02_submit_userGWAS.sh "/path/to/gsem" GGE --dry-run

bash 02_submit_userGWAS.sh "/path/to/gsem" FE --dry-run

bash 02_submit_userGWAS.sh "/path/to/gsem" GGE_no_CAE --dry-run
```

Omitting `--dry-run` submits the corresponding SLURM job array.

These launchers were configured for the UCT HPC environment. Partition, account, R-library paths and computational resources may require adjustment on other systems.

R analyses should be executed on allocated compute nodes rather than directly on the HPC login node.

### Stage 3: Combine chromosome-level association results

`03_combine_results.R` combines chromosome-level outputs for each latent factor.

The script verifies:

- Complete coverage of chromosomes 1–22.
- Completeness and consistency of chromosome chunks.
- Expected SNP counts per chromosome.
- SNP identifier uniqueness across the complete dataset.
- Correct factor identities and model paths.
- Required output columns.
- Absence of reported model errors.
- Valid association P-values.

It also records genome-wide significant SNP counts and smoothing diagnostics.

Results are written incrementally, with the completed outputs published from a staging directory. Existing final results are not overwritten.

The corresponding launcher is `03_submit_combine.sh`.

For example:

```bash
bash 03_submit_combine.sh "/path/to/gsem" GGE --dry-run
```

The same interface applies to `FE` and `GGE_no_CAE`. Removing `--dry-run` submits the combination job.

Combination should be performed only after all chromosome-level GWAS jobs for the selected analysis have completed successfully.

### Stage 4: Independently validate combined results

`04_validate_results.R` independently checks the combined genome-wide association files against the harmonised chromosome-level inputs and the expected reference results.

The validation includes:

- Total SNP counts and chromosome coverage.
- SNP identifier uniqueness.
- Agreement of SNP identities with the harmonised inputs.
- Consistency of SNP positions and alleles between the two factor outputs.
- Correct factor-path labels.
- Association P-value validity.
- Model-error checks.
- Genome-wide significant SNP counts.
- Q-SNP heterogeneity summary statistics.
- Maximum absolute smoothing statistics.
- MD5 checksums of final association files.

The script writes validation reports and R session information under:

`validation/<analysis>/`

For example:

```bash
Rscript 04_validate_results.R "/path/to/gsem" GGE
```

Equivalent commands apply to `FE` and `GGE_no_CAE`.

The validator requires the combined results generated by the consolidated workflow and does not modify the SNP-level association files.

For the CAE-exclusion analysis, the verified GGE-factor result contained 68 genome-wide significant SNPs. The corresponding sensitivity-analysis brain-factor output is archived separately; its genome-wide significant SNP count has not been independently established in this verification record.

## Verification of the consolidated workflow

The consolidated scripts underwent input validation, small-scale model execution and integration testing using the UCT HPC environment.

The following checks were completed:

| Workflow component | Verification performed |
|---|---|
| Harmonised input preparation | Original archived GGE and FE inputs passed structural validation |
| Primary GGE runner | Corrected LDSC input validation and 100-SNP execution test |
| FE runner | LDSC input validation and small-scale execution test |
| GGE excluding CAE | Nine-phenotype LDSC input validation and small-scale execution test |
| GWAS SLURM launcher | Syntax validation and dry runs for all three analyses |
| Result combination | Functional test using 2,178 synthetic SNP identifiers distributed across 22 chromosomes |
| Split-chromosome handling | Successful recombination of a two-part chromosome 2 |
| Combination SLURM launcher | Syntax validation and dry runs for all three analyses |
| Independent output validator | Functional test of chromosome coverage, SNP identity, factor labels and QC reporting |

The synthetic combination test was designed to verify file handling, chromosome coverage, chunk completeness and SNP uniqueness. It does not constitute an independent scientific replication of the original GWAS associations.

Similarly, the small-scale model tests establish that the consolidated runners can execute the specified models and save compatible results, but do not demonstrate genome-wide numerical equivalence with the original archived outputs.

The verified genome-wide SNP counts and significant associations reported above therefore originate from the completed original analyses, not from a full genome-wide rerun of the consolidated pipeline.

## Reproducibility scope and data preservation

The repository documents the definitive model specifications, required covariance objects, input preparation, computational execution, result combination and validation procedures.

Reproduction requires access to the original harmonised SNP summary statistics, the corresponding LDSC covariance objects, a compatible Genomic SEM installation and sufficient computational resources.

The initial preparation of harmonised SNP summary statistics from source GWAS files is outside the scope of these consolidated scripts. The workflow therefore begins from the archived harmonised Genomic SEM SNP inputs.

Original GWAS datasets, LDSC objects, chromosome-level outputs, completed genome-wide association files and associated execution records remain in controlled research storage.

The scripts deliberately prevent accidental overwriting of completed outputs. A new full execution should use a separate analysis directory.

The upstream LDSC specifications are documented in `02_GenomicSEM_LDSC`, factor-model development is documented in `03_EFA_CFA`, and functional mapping and annotation using FUMA are documented separately in `05_FUMA_Locus_Mapping`.
