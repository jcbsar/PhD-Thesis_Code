# Multivariable Mendelian Randomisation

This directory contains the R scripts and reproducibility documentation for the exploratory multivariable Mendelian randomisation (MVMR) analyses presented in Chapter 5.

The analyses examined the associations of genetically proxied educational attainment and type 2 diabetes with six epilepsy outcomes, using jointly LD-clumped instruments and inverse-variance-weighted multivariable Mendelian randomisation.

The analytical workflow includes instrument preparation, cross-exposure harmonisation, MVMR estimation, and conditional instrument-strength sensitivity analyses.

The final MVMR estimates were reproduced from the archived harmonised datasets and validated against the results reported in the thesis.
