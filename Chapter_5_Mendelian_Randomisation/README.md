# Chapter 5: Mendelian Randomisation

   This directory contains the R scripts used for the Mendelian randomisation analyses presented in Chapter 5 of the PhD thesis *From genetic risk to brain structure: An integrative investigation of epilepsy and functional dissociative seizures*.

   The analyses include univariable Mendelian randomisation, reverse-direction Mendelian randomisation, and exploratory multivariable Mendelian randomisation.

   Scripts and reproducibility documentation are organised by analytical component.
